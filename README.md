# مختبر الفيزياء

موقع عربي تفاعلي للصف الثاني الثانوي — مستر مصطفى السايس · MS Academy.

## الملفات

- `index.html`: الصفحة الرئيسية، الوحدات، المختبر الافتراضي، بنك الأسئلة، مرجع القوانين، وقارئ PDF محلي.
- `lesson1.html`: شرح الدرس الأول «القياس الفيزيائي»، محاكاة القدمة ذات الورنية، مسائل محلولة، واختبار تفاعلي من 10 أسئلة.
- `.github/workflows/pages.yml`: نشر تلقائي للموقع على GitHub Pages عند تحديث فرع `main`.

قارئ PDF يعرض الملف الذي يختاره الطالب من جهازه داخل المتصفح دون رفعه إلى الموقع.
