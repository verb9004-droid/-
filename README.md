# مختبر الفيزياء

موقع عربي تفاعلي للصف الثاني الثانوي — مستر مصطفى السايس · MS Academy.

## محتويات الموقع

- `index.html`: الوحدات، المختبر الافتراضي، بنك الأسئلة، القوانين، وقارئ PDF.
- `lesson1.html`: صفحة الدرس الأول وقراءة/تحميل المذكرة.
- `مذكرة_الدرس_الأول_القياس_الفيزيائي.pdf`: مذكرة شرح من 13 صفحة مستندة إلى الفصل الأول من كتاب الفيزياء، مع رسومات توضيحية ومسائل واختبار وإجاباته.
- `.github/workflows/pages.yml`: نشر تلقائي على GitHub Pages عند تحديث فرع `main`.

المذكرة تلخص المحتوى وتشرحه بأسلوب مستقل، وترشد إلى صفحات الكتاب الأصلية (17–37).
